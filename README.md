# MentalHealthAssistant

## Возможности

- **Проверка по лицу.** Семь эмоций (радость, спокойствие, грусть, злость, тревога, неприязнь, удивление) и подробная мимика по 68 точкам лица: раскрытие глаз, частота морганий, раскрытие рта, подъём уголков рта, положение и сведение бровей, наклон головы.
- **Проверка по голосу (по желанию).** Средняя высота тона, колебания тона и громкости, яркость голоса. Всё считается в браузере через Web Audio API.
- **Выводы и подсказки.** Короткие наблюдения и простые шаги на ближайший час. Результат сравнивается с вашим средним уровнем напряжения за 30 дней.
- **Разговор.** Локальный помощник на заготовленных сценариях: узнаёт темы (тревога, сон, усталость, грусть, злость и другие), предлагает простые приёмы и задаёт уточняющие вопросы. Это не нейросеть и не живой специалист, и приложение говорит об этом прямо. На кризисные фразы отвечает отдельным сообщением с просьбой обратиться за помощью.
- **Дневник.** Регистрация и вход, история проверок, график напряжения и распределение эмоций.
- **Шесть языков:** русский (по умолчанию), English, 中文, Deutsch, Français, Español.
- **Адаптивный интерфейс** для телефона и компьютера, светлая и тёмная темы, спокойная палитра без лишних эффектов.

## Технологии

| Часть | Что используется |
|---|---|
| Сервер | Python, Flask, Flask-JWT-Extended, SQLite |
| Лицо | face-api.js (TinyFaceDetector, 68 landmarks, FaceExpressionNet), работает в браузере |
| Голос | Web Audio API (автокорреляция для тона, спектральный центроид) |
| Графики | Chart.js |
| Интерфейс | HTML, CSS и JavaScript без фреймворков |

## Приватность

Видео и звук обрабатываются только в вашем браузере и никуда не отправляются. На сервер сохраняются только числовые результаты проверок и текст выводов. История разговора с помощником хранится только в браузере (localStorage) и на сервер не попадает.

## Быстрый старт

Нужен Python 3.10 или новее.

```bash
git clone https://github.com/whotyc/MentalHealthAssistant.git
cd MentalHealthAssistant

python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5000, создайте аккаунт и сделайте первую проверку.

Камера и микрофон в браузере работают только на `localhost` или по HTTPS. Адрес вида `http://192.168.x.x` не подойдёт. Чтобы проверить приложение на телефоне, используйте HTTPS-туннель (например, `cloudflared tunnel --url http://localhost:5000` или `ngrok http 5000`) или разверните приложение на хостинге.

При первом запуске приложение само создаёт секретный ключ для входа (файл `.secret_key`) и базу данных `mental_health.db`. Настраивать ничего не нужно.

## Настройки (необязательно)

Задаются переменными окружения:

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `JWT_SECRET_KEY` | Секрет для подписи токенов (если не задан, берётся из `.secret_key`) | создаётся автоматически |
| `HOST` | Адрес, на котором слушает сервер | `127.0.0.1` |
| `PORT` | Порт | `5000` |
| `FLASK_DEBUG` | `1` включает режим отладки | выключено |

## API

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/register` | Регистрация |
| POST | `/api/login` | Вход, выдача JWT |
| GET | `/api/me` | Текущий пользователь |
| GET | `/api/measurements` | История проверок |
| POST | `/api/measurements` | Сохранить проверку |
| DELETE | `/api/measurements` | Удалить все записи пользователя |

## Ограничения

- Распознавание эмоций по лицу и напряжения по голосу даёт оценку, а не диагноз. Пороги метрик общие и не калибруются под конкретного человека.
- Модели распознавания лица и Chart.js загружаются с CDN (jsdelivr), поэтому для первого запуска нужен интернет.
- Помощник отвечает по заготовленным сценариям и не понимает сложный контекст.
- Нет ограничения числа запросов к `/api/login`; для публичного развёртывания добавьте, например, Flask-Limiter.
- SQLite подходит для демо и личного использования, для продакшена лучше PostgreSQL.
